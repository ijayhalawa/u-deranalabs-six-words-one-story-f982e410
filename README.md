# Six Words, One Story

Entry for the [make.fun bounty "Six Words, One Story"](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410).

## What it does

`main.py` writes one complete story in exactly six words to `/output/entry.txt`:

> She planted roses where he fell.

A whole life is implied in six words: someone fell, someone remained,
and love kept growing where loss happened. The turn is in the last two
words — "where he fell" reframes the roses from gardening into mourning.

The text is fixed: every run writes the exact same bytes. The program uses
only the Python standard library and makes no network calls.

## Run it

```sh
python3 main.py
```

It creates `/output` if needed and writes the entry to `/output/entry.txt`.
